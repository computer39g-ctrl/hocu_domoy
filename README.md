# «Хочу домой» — интерактивный социальный лонгрид (версия 2.0)

**Сайт готов к статической публикации.** Это независимый учебный прототип, не страница официальной организации, не форма сбора пожертвований и не реальный случай конкретной собаки.

## Состав проекта
- `index.html` — адаптивный сайт (без сборщика и сторонних JS-библиотек).
- `assets/hero-ryzhiy.webp` — оригинальная **художественная иллюстрация**, созданная для обложки с помощью ИИ, ~300–500 КБ.
- `README.md` — инструкция и сведения об источниках.

Содержание: обложка и история, интерактивный день из 5 сцен, причины бездомности, инструкция при встрече собаки, фотогалерея из снимков Unsplash, ссылки на фонды «РЭЙ» и «НИКА», интерактивный список действий, призыв и расшаривание (Telegram, VK, обычное меню, копирование адреса).

## Важное замечание о фотографиях
**На обложке — художественная иллюстрация.** Фотографии из фотобанка Unsplash в самой истории и галерее — иллюстративные снимки *разных настоящих собак*. Они не документируют жизнь вымышленного пса Рыжего. Фотографии загружаются с Unsplash при наличии доступа к интернету; для гарантированной работы офлайн их нужно локально скачать и положить в `assets/` с сохранением лицензии/атрибуции. Сайт работает без них, но фотогалерея без интернета отображает нейтральный фон.

## Как посмотреть
Откройте `index.html` в браузере. Самый удобный вариант для проверки интерактивности — локальный сервер:

```bash
python -m http.server 8000
```

Затем откройте http://localhost:8000/ . Когда сайт запущен как локальный файл (`file://`), кнопка «Поделиться» объяснит, что для неё нужен опубликованный адрес.

## Как опубликовать бесплатно (GitHub Pages)
1. Зайдите в GitHub и создайте новый **публичный** репозиторий, например `hochu-domoy`.
2. Загрузите в его корень **оба файла/папку**: `index.html` и `assets/hero-ryzhiy.webp` (можно загрузить через Add file → Upload files). `README.md` можно тоже.
3. Откройте Settings → Pages → Build and deployment → Deploy from a branch.
4. Выберите ветку `main`, папку `/(root)`, сохраните.
5. После завершения публикации сайт будет доступен по адресу формата `https://USERNAME.github.io/hochu-domoy/`.
Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

**Нельзя загружать только `index.html`, забыв папку `assets`: обложка исчезнет.** Папка `assets` обязательна.

## Если нужна Tilda
Самостоятельную страницу `index.html` нельзя автоматически импортировать целиком в редактор Tilda без доработки. Для версии Tilda нужно воспроизвести блоки стандартными средствами и/или выделить отдельные виджеты (например, таймлайн) в блок T123. Документация: https://help.tilda.cc/html
